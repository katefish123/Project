为什么合并

两次采样先旋转、再去畸变：两次双线性叠加两次低通，缓存带宽翻倍。×2
一次采样H 与 Brown 串成一条逆映射：每个输出像素只取一次 2×2 邻域。×1
合并后边缘更锐、带宽更低；代价是坐标链路必须全定点、帧内参数不可变。

算法细节

逆仿射 + Brown 畸变，合并为一次 2×2 采样

03/ 04
A

逆仿射

u = a00·x + a01·y + a02
v = a10·x + a11·y + a12
六项均为 signed40 / Q24，底行 [0 0 1]；把目标像素映射到去畸变理想源平面。
B

Brown 畸变

RADIAL + TANGENTIAL
r² = X² + Y²
X′ = X(1 + k₁r² + k₂r⁴) + 2p₁XY + p₂(r² + 2X²)
Y′ = Y(1 + k₁r² + k₂r⁴) + p₁(r² + 2Y²) + 2p₂XY
k₃ 固定为 0；k₁/k₂ 径向、p₁/p₂ 切向；由 9×6 棋盘标定。
关键洞察：畸变公式本身就是"理想 → 观测"的正向映射；
硬件需要"观测 → 理想"，直接代入即可，无需解析逆。
