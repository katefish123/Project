### 架构特点

- 五时钟域异步隔离：27 / 148.5 / 92.8125 / 125 / 74.25 MHz
- 双 Bank 采集 + 帧代数，坏帧拒绝、旧帧不误释放
- 128×2 瓦片缓存，64 像素连续突发写回
- 240 位参数整组快照，帧边界锁存
- 整帧写完才发布新代数，显示端帧边界切换

### 两种地址顺序

- 轴对齐（0° / 180°）：光栅逐行读取，源行命中率高
- 旋转 / 缩放：128×128 分块遍历，块内复用源缓存；末行带裁剪

## P2 作品亮点

- 主标题：作品亮点
- 副标题：三个关键词——单次重采样 · 分块缓存 · 帧同步锁参

### 创新点

1. **单次重采样**：镜头畸变与角度变换合并成一条逆映射，每个输出像素只插值一次。
2. **分块缓存**：128×2 瓦片 + 128 行容量，旋转时源行在块内反复命中。
3. **帧同步锁参**：六项 Q24 系数整组跨时钟传递，只在下一幅新帧首拍生效。
4. **双 Bank 采集**：释放必须带回帧代数，坏帧拒绝、旧帧不误释放。
5. **四层证据链**：数值模型 → RTL 仿真 → 综合网表 → 实板录像；每条结论绑定源码哈希与时间目录，不以"仿真通过"代替"上板通过"。

## P3 算法细节

- 主标题：算法细节
- 副标题：逆仿射 + Brown 畸变，合并为一次 2×2 采样

### 逆仿射

u = a00·x + a01·y + a02
v = a10·x + a11·y + a12

六项均为 signed40 / Q24，底行 [0 0 1]；把目标像素映射到去畸变理想源平面。

### Brown 畸变

r² = X² + Y²
X′ = X(1 + k1r² + k2r⁴) + 2p1XY + p2(r² + 2X²)
Y′ = Y(1 + k1r² + k2r⁴) + p1(r² + 2Y²) + 2p2XY

k3 固定为 0；k1/k2 径向，p1/p2 切向；由 9×6 棋盘标定。

### 关键洞察

畸变公式本身就是"理想 → 观测"的正向映射；硬件需要"观测 → 理想"，直接代入即可，无需解析逆。

### 定点格式

| 量 | 格式 |
| --- | --- |
| 仿射 H | signed 40 bit / Q24 |
| 内参 fx fy cx cy | Q16 |
| 畸变 k1 k2 p1 p2 | Q26 |
| 插值权重 | UQ0.8 |
| 内部坐标 | signed 40 bit（8 位亚像素） |

### 坐标流水线

仿射乘加 → 归一化 → 径向 → 切向 → 反归一化 → 缓存 → 插值 → 写回（坐标链路 11 级）

### 边界

- 越界标记 outside，最终填黑，避免越界读取
- 小角度自动等比放大防黑，裁剪合并进矩阵，不增加第二次插值
- 双线性 / 最近邻共用同一条坐标与缓存链路
