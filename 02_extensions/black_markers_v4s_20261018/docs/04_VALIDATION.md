## 本次真实上板经过

1. 使用 V4S 精确 sbit 下载成功；完整 Verify 因缺配套 smsk 停止。
2. OBS 出现彩条及 `DDR ALIGN ERROR`。KEY0 后仍有提示，用户报告 LED6 不亮。
3. 用户称板子有点烫并断电；没有本次温度读数，不能给出温升数值。
4. 用户重新供电后，重复下载完全相同的 V4S sbit；Program 和状态读取成功。
5. 用户反馈“有矫正页了”。对四角保持可见时在中间放入/移开手指、观察短时变化的检查，回复“可以了我觉得”。
6. 用户要求结束测试。保留当前版本，不继续延长运行。

故障图 `evidence/board/obs_ddr_align_error.png` 是失败时刻的截图。本包没有本次成功出图的独立照片/录像，因此以用户现场反馈记录其证据等级，不补造演示结果。

## 已知问题

- V4S 顶层锁存历史 memory_detail；reason7 同时承载源通路和内存故障，可能在当前 source_fault 时仍显示历史 ALIGN。屏幕提示与 LED6 不一致具有可达的代码条件，但本次真实首次物理故障根因尚未确认。
- 同版重新上电/重烧后恢复出图，不等于修复了真实 DDR、源 FIFO 压力或长期停更问题。
- 固定 ROI 会受取景位置、黑色正文和阴影干扰；没有任意位置黑标跟踪、完整镜头标定或精确几何验收。
- 未测长期稳定性、重连全过程、实际新图帧率、温升、光学清晰度和端到端延迟。
- 原回执中的 hardware_accepted=false 等字段原样保留；本次短时用户反馈不将其改写为全面验收通过。
