# 硬件接线与操作

## 接线

相机 HDMI 输出 → FPGA HDMI 输入；FPGA HDMI 输出 → VC-002Pro 采集卡 HDMI 输入；采集卡 USB → 电脑；下载器 → FPGA JTAG。板卡供电、HDMI 方向和端口以板卡标识为准。

相机有效输入为 1920×1080 逐行。相机、板卡、采集卡输入/输出的扫描速率与传输格式须匹配。OBS 只是查看采集卡内容，界面显示 30 fps 不等于校正算法输出 30 张不同结果/秒。

## 本版按键

| 按键 | V4S 行为 |
|---|---|
| KEY0 | rst_n 复位 |
| KEY1 | 按住强制彩条，松开正常显示 |
| KEY2 | 最近邻选择；默认松开使用双线性 |

KEY1 在本版是强制彩条键。按键定义以本包 `video_correct_ddr_top.v` 为准。

## LED

| LED | 顶层连接含义 |
|---|---|
| 0 | 心跳 |
| 1 | DDR 初始化完成 |
| 2 | DDR 启动读写自检通过 |
| 3 | 已有完整有效结果 |
| 4 | frame_error 或 input_wait |
| 5 | 显示欠载 |
| 6 | HDMI配置/engine/PHY/ALIGN/自检综合故障 |
| 7 | HDMI RX/TX 芯片配置完成 |

LED7 配置完成不等于当前相机输入有效。LED6 不包含全部 source_fault，不能仅凭此灯熄灭认定整条数据通路无故障。LED4 也不能单独区分输入等待、坏帧和算法拒绝。

## 固定黑标窗口（原生 1920×1080 坐标）

| 角 | X 范围 | Y 范围 |
|---|---|---|
| TL 左上 | 580～681 | 86～187 |
| TR 右上 | 1410～1511 | 174～275 |
| BR 右下 | 1480～1581 | 920～1021 |
| BL 左下 | 226～327 | 886～987 |

角标须落入对应区域，正文/阴影不要进入这些区域。参数固定在 FPGA 逻辑中；修改说明或 JSON 不会改变已烧录程序，必须改源码重新验证和构建。

## 屏幕观察

已有结果时侧栏 FRAME 是显示代数快照，PUB 是发布计数，CAP 是接纳计数，REJ 是拒绝计数；MARK/SHAPE/OVER/SOLVE 分别对应角标、帧形状、溢出、求解类别。AGE/HELD 表示图像年龄。此类跨域诊断快照有延迟，不能把数值相减直接当作每帧实测延迟。

彩条可能来自没有完整结果或 KEY1 被按住。出现 ALIGN 横幅时保留状态、LED、帧号与截图后排查；本版存在历史状态误归因，不能直接认定板卡损坏。断电会丢失 CRAM 配置，重新供电后需再次显式下载。

本次没有温度仪器读数，也没有长期运行结论；测试时若板卡明显发热，应按照板卡供电与散热要求安排运行时间和散热。
